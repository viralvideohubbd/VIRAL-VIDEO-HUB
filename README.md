# Viral Video Hub — Screenshot-style Telegram Mini App

এটি আপনার দেওয়া screenshot-এর layout অনুসরণ করে বানানো একটি Telegram Mini App UI:
- VIRAL VIDEO HUB header
- menu/search
- সব ভিডিও/ট্রেন্ডিং buttons
- category chips
- Trending Videos section
- video cards + stats
- WATCH / DOWNLOAD NOW
- bottom Home/Profile navigation

এটি UI prototype। বাস্তব ভিডিও/কনটেন্ট চালাতে আপনার নিজের অনুমোদিত backend/API এবং database যুক্ত করতে হবে।

Telegram Mini App হিসেবে HTTPS hosting-এ index.html প্রকাশ করে BotFather-এর Mini App/Menu Button-এ URL সেট করুন।
